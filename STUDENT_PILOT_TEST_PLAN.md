# EcoNova Campus Recycling Mobile MVP v1.0.0 — Student Pilot Test Plan

## Objective
The objective of this pilot test is to evaluate the **usability, intuitive flow, and discoverability** of the EcoNova mobile application among campus student testers.

---

## Student Tasks (Natural Language Instructions)
Facilitators must provide testers with only the task statements below. **Do NOT explain how to accomplish the task inside the task statement itself.**

### Task 1 — Get Started
> "Open EcoNova and complete the onboarding setup until you reach the Home screen."

### Task 2 — Find a Station
> "Find a recycling station located near your campus building."

### Task 3 — Perform a Recycle Action
> "Simulate or enter a station code to complete a recycling submission for 2 plastic bottles."

### Task 4 — Check Point Balance
> "Find out how many Green Points you currently have available to spend."

### Task 5 — Join a Challenge
> "Find a campus recycling challenge and join it."

### Task 6 — Check Competition Rank
> "Find your position on the student leaderboard and check which faculty is currently winning the cup."

### Task 7 — Review Environmental Impact
> "Find out how much CO2e emissions you have avoided and how many trees that equals."

### Task 8 — View Achievements
> "Check which eco badges you have unlocked so far."

### Task 9 — Redeem a Campus Reward
> "Find a reward voucher you can afford and redeem it."

### Task 10 — Profile & Settings
> "Locate your student profile and check your application settings."

---

## Usability Measurement Framework

For each student task, facilitators will record:
* **Task Outcome:** Success / Partial Success / Failure
* **Completion Time:** Time taken in seconds
* **Wrong Attempts:** Count of incorrect button taps or misdirections
* **Hints Required:** Number of verbal prompts requested/needed
* **Tester Feedback:** Verbatim comments or confusion noted

---

## Usability Key Performance Indicators (KPIs)

1. **Task Success Rate:**
   $$\text{Success Rate} = \frac{\text{Number of Successful Tasks}}{\text{Total Tasks Executed}} \times 100\%$$
   *Target:* $\ge 90\%$

2. **Average Task Completion Time:**
   Average time per task across all participants.
   *Target:* $< 30\text{ seconds per task}$

3. **Error Rate:**
   Average number of misclicks or navigation errors per task.
   *Target:* $< 0.5\text{ errors per task}$

4. **Assistance Rate:**
   Percentage of tasks requiring facilitator intervention.
   *Target:* $< 5\%$

5. **Overall Usability Satisfaction:**
   Average score on a 1–5 scale across usability feedback questions.
   *Target:* $\ge 4.2 / 5.0$
